# Reproducibility guide

## What “reproducible” means here

The project separates three levels that are often conflated:

1. **Result audit:** inspect frozen configurations, aggregate results,
   acceptance calculations, manifests, and hashes without rerunning a model.
2. **Computational reproduction:** rerun a named experiment with the same
   upstream model/data revisions and compatible numerical environment.
3. **Independent replication:** repeat the scientific test with new seeds,
   models, datasets, or implementations. The current repository supports this
   work but does not claim it has already happened unless explicitly recorded.

The public evidence bundle primarily guarantees level 1. Full level-2 reruns
can require gated models, upstream datasets, substantial GPU time, and hundreds
of gigabytes of temporary cache.

## Provenance chain

For a headline claim, begin at [`EVIDENCE_INDEX.md`](EVIDENCE_INDEX.md) and
follow this chain:

```text
claim ID
  -> author-written research log
  -> objective agent report
  -> frozen config and protocol
  -> source code + tests at the recorded Git revision
  -> MLflow run metadata
  -> checksummed result/audit artifact
```

If two records disagree, do not silently select the stronger wording. Consult
[`ERRATA.md`](ERRATA.md), use the more conservative evidence label, and preserve
both source records.

## Environment

The original WSL environment is located outside this repository and is not a
portable artifact. The tracked [`requirements.txt`](../requirements.txt), run
manifests, and resolved configurations record the relevant software surface.
Several Llama runs record Python 3.12.13, PyTorch 2.12.0+cu130, Transformers
5.12.1, and an NVIDIA RTX 5090 Laptop GPU; numerical equivalence is only claimed
where the corresponding report explicitly audits it.

Create an isolated environment and install the tracked requirements. Install
[`requirements-dev.txt`](../requirements-dev.txt) to run the test suite; the
historical shared experiment environment did not include pytest itself. Before
running an experiment, inspect its resolved configuration for machine-specific
model, data, cache, or output paths. Historical absolute paths are provenance,
not portable defaults.

Run the CPU/unit verification suite from the repository root:

```bash
python -m pytest -q
```

GPU experiments should be launched only after reading their protocol and
configuration. Several runners are resumable and require a timezone-aware hard
stop. Do not infer a safe command merely from the script name.

## Data-split discipline

- EXP-003 selected candidate layers using validation and evaluated the frozen
  decision on test.
- EXP-004 H1 used ARC-Easy official train only, split into `D_fit` and
  `D_discover`; official validation and test were not accessed.
- EXP-004 H2 froze both reward-specific tuning selections before opening the
  official test gate. The test split was then used for the three frozen search
  variants.

Public artifacts retain split-access flags and gate evidence. Re-running test
for exploratory tuning would invalidate the recorded interpretation.

## MLflow

MLflow is a local tracking ledger, not a public web service. A raw run ID alone
is therefore not publicly resolvable. The public HF bundle exports canonical
run metadata (parameters, latest metrics, selected tags, status, and artifact
hashes) to JSON. The local `mlruns.db` and `mlruns/` tree remain private because
they contain machine-local paths and abandoned-run history.

Three early abandoned runs were still marked `RUNNING` at the 2026-09-04 audit.
They are labelled stale and excluded from canonical exports; the source database
is intentionally not rewritten.

## Models, datasets, and large caches

The release does not redistribute upstream datasets, base-model weights,
fine-tuned checkpoints, raw hidden-state tensors, or prefix-cache pages. Obtain
models and datasets from their upstream sources under their applicable terms.
Rebuildable caches can be regenerated by the relevant runner. This policy keeps
the evidence package reviewable and avoids treating 272 GB of machine cache as
scientific evidence.

## Public bundle verification

Build the selected evidence package with:

```bash
python scripts/build_public_evidence.py
```

The command fails if the destination already exists, a selected source file is
missing, a bounded file set changes unexpectedly, or its expected policy
classification is absent. It preserves selected repository `artifacts/...`
paths and writes a SHA-256 manifest plus exact HF URIs alongside the bundle.
Compare that manifest with the tracked copy under `release/manifests/` and the
file displayed on HF. Historical log pointer resolution is specified in
[`PUBLIC_ARTIFACTS.md`](PUBLIC_ARTIFACTS.md).
