## Question (EXP-001 §2)

Verify three hypotheses on frozen DeBERTa-v3-base / CLINC150:

- $H_1$ **Non-inferiority**: an intermediate layer alone can show close performance to the final layer.
- $H_1'$ **Superiority**: some intermediate layer performs better than the final layer.
- $H_2$ **Recoverability**: mid layers can correct samples the final layer misclassifies.

EXP-001's plain linear probe gave false negatives (mid-layer collapse). EXP-003
re-runs the verification under three probe families that EXP-002 validated
(centered plain, LN plain, ridge/OLS), so the answer does not depend on one
optimisation path.

**Findings:**

1. **The non-convergence at 1000ep is a compute-budget artefact, not a
   fundamental failure.** Every run converges given 2000–9000 epochs (centered)
   or 600–4100 epochs (LN). The 1000ep cap was simply too small for mid-layer
   Xavier convergence on near-constant CLS features.
2. **Converged accuracy is much higher than at 1000ep.** Centered L6 (hardest):
   0.295 → **0.762**; centered L4: 0.347 → **0.807**; LN L6: 0.602 → **0.881**.
   Converged mid layers strongly exceed converged L12: centered L7/L10
   0.923/0.918 vs L12 0.884; LN L7 0.923 vs L12 0.871 — the §2 superiority
   verdict **strengthens** with convergence, not weakens.
3. **LN is 2–4× more compute-efficient** than centered plain (convergence
   epochs 625–4057 vs 857–8954), consistent with LN's per-sample
   normalisation directly addressing the CLS variance collapse.
4. **Most gains arrive late.** Centered mid layers typically need 5000–9000
   epochs: e.g. L6 reaches 0.493@5000, 0.627@10000, 0.762@20000 — still rising
   at the cap (best_epoch = 20000 for L4/L6/L7/L8). The min_delta=1e-4 /
   patience=100 early-stop rule is strict: it can trigger during a temporary
   flat stretch and cut off slow tail gains (e.g. centered L4 would stop at
   8954 with ≈0.72, but running to 20000 reaches 0.807).
5. **Implication for the design verdict:** the 1000ep cap remains the fair
   comparison budget (more epochs would be an unequal compute spend), but the
   probe's non-convergence at 1000ep is now explained as **slow convergence
   (~10–20× beyond the cap for mid layers)**, not as a probe pathology. A
   future run that wants converged mid-layer accuracy cheaply should use LN
   (or OLS-init, per EXP-002 03h) rather than centered plain with Xavier init.

## 6. Observations

1. All three hypotheses are very strongly supported by three structurally
   different probes (fixed-transform linear, learnable-normalisation linear,
   closed-form least-squares) — the finding is not probe-specific.
2. Mid layers beat the final layer on test in **every seed** for both gradient
   families (all ΔA₁ < 0), with CIs that exclude zero.
3. H2 recoverability is large and broad: 78–89% of final-layer errors
   recoverable by some mid layer; D_JS ≈ 0.007–0.020 (near-uniform class
   distribution); 508–690 recoverable samples per seed (all ≫ 225).
4. L6 is the hardest mid layer (centered 0.295, LN 0.602, ridge 0.914); ridge
   fully recovers it, confirming EXP-002's L6-collapse finding.
5. Centered plain's candidate (L11) is the highest layer, closest to L12;
   LN/ridge candidates (L10) sit mid-stack with L7 also ≈ L10 (LN: 0.872 vs
   0.875). The best layer is probe-dependent but always intermediate.
6. Convergence asymmetry: L12 converges for both gradient probes while mid
   layers mostly do not — the near-constant CLS component slows mid-layer
   optimisation specifically.

## 7. Interpretation, alternatives, limitations

- The EXP-001 false negative is resolved: the plain probe's collapse was an
  optimisation artefact, not missing signal. A biased linear classifier
  (hypothesis class unchanged) suffices once the solver can reach the optimum.
- Centered plain supports H1'/H2 despite 92% non-convergence because L11 is
  close enough to L12 that a partially-converged probe already separates
  classes; deeper layers (L4–L8) are under-recovered (0.29–0.69) yet still
  contribute to the oracle.
- Val/test ranking flip for centered plain: val L11 (0.875) < L12 (0.877) but
  test L11 (0.862) > L12 (0.852). Tiny gaps (0.002 val / 0.010 test), tight CI
  [0.008, 0.010] — normal val/test variation, protocol-compliant (candidate by
  val, judged on test).
- Limitations: single backbone (DeBERTa-v3-base) / single dataset (CLINC150);
  CLS pooling only (EXP-002 task 06 showed non-CLS tokens do not collapse);
  ridge has point estimates only (no CI); 9–29 classes have no final-layer
  errors and hence no defined $R_{l,c}$.
