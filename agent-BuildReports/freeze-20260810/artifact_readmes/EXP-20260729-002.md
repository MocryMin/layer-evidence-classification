# EXP-20260729-002 - Artifacts

Diagnostic campaign: why does a pure linear probe collapse to near-random on
DeBERTa-v3-base mid-layer CLS, and what fixes it. Parent experiment
EXP-20260729-001 (mainline paused). Full write-up:
`reports/experiments/EXP-20260729-002--linear-probe-midlayer-collapse.md`.

## Provenance

- Git commit / MLflow run ID: see the experiment report header.
- Backbone: `microsoft/deberta-v3-base` (frozen) + a full-FT variant
  (`models/deberta-v3-base-clinc150-ft/`, task 3c).
- Dataset: CLINC150 `plus`, OOS (label 42) dropped, 150 in-scope classes,
  splits 15000/3000/4500. Prompt `Classify the intent: {utterance}` (task 3b
  uses the pure-utterance prompt).
- Shared frozen-backbone cache: `artifacts/EXP-20260729-001/cache/` (CLS of
  layers 1..12, float16). Per-variant caches live under `03b_no_prompt/cache/`,
  `03c_ft_backbone/cache/`, and `03g_ridge_alpha_grid/cache_ft_noprompt/`.

## File schemas

- `feature_stats_*.json`: list of per-layer dicts with keys `layer`, `n_samples`,
  `dim`, `mean_norm`, `mean_abs`, `inter_sample_std_{mean,median,min,max}`,
  `within_sample_std_mean`, `class_signal_ratio`, `between_class_var`,
  `within_class_var`, `participation_ratio`, `top1_var_frac`, `top10_var_frac`.
- `02_variance_collapse/per_layer_collapse_summary.json`: `rows[]` per layer with
  the feature stats above PLUS probe val acc - `plain_adamw_val_{mean,std}` /
  `plain_adamw_test_mean` (EXP-001 mainline lr=1e-3, 10 seeds), `lbfgs_val`
  (03d, representative layers), `ols_val`/`ols_test` (03g Ridge alpha=1e-6),
  `ln_val` (03a, seed 17). Merges feature stats + accuracy so the collapse
  (low inter_std + near-random plain-AdamW acc) and rescues (OLS/LN/LBFGS) are
  in one table. `sources` field lists the originating artifacts.
- `lr_grid_*.json` / `*_probe_*.json`: dict keyed `layer_{L}_lr_{lr:g}` with
  `best_val_acc`, `best_val_nll`, `best_epoch`, `final_val_acc`, `final_val_nll`.
- `ln_ablation_*.json`: dict keyed `{head_type}_layer_{L}` with `best_val_acc`,
  `best_val_nll`, `final_val_acc`.
- `03a_ln_ablation/transformed_feature_stats.json`: `per_head[{head}][str(L)]`
  with `best_val_acc`, `best_epoch`, and the stats of the *transformed* train
  features using the trained transformation (plain = identity; norm_only = fixed
  normalisation; ln/affine_only use trained gamma/beta):
  `inter_sample_std`, `participation_ratio`, `top1_var_frac`,
  `class_signal_ratio`, `mean_norm`.
- `optimizer_comparison.json`: `{adamw, sgd, lbfgs}` each a dict keyed
  `layer_{L}_lr_{lr:g}` with `best_val_acc` etc.
- `ft_history.json`: list of per-epoch `{epoch, train_loss, val_acc, val_nll,
  test_acc, test_nll}`.
- `03f_ridge/ridge_results.json`: `per_layer[str(L)]` with `ridge_val/test`,
  `ridge_no_intercept_val`, `plain_adamw`, `lbfgs` (alpha=10 fixed).
- `03g_ridge_alpha_grid/ridge_*.json`: `per_layer[str(L)]` with `by_alpha[str(α)]`
  = `{alpha, val_acc, test_acc}` and `best_alpha/best_val_acc/best_test_acc`;
  `summary.json` consolidates the three caches (cross-cache val/test at α=1e-6
  and α=10, best α per layer).
- `03h_adam_ablation/adam_ablation.json`: `conditions[name]` with `summary`
  (`init`, `optimizer`, `weight_decay`, `batch`, `init_val_acc`, `best_val_acc`,
  `best_epoch`, `final_val_acc`, `final_test_acc`, `n_epochs`, `stopped`) and
  per-epoch `history` (`epoch`, `train_loss`, `val_acc`, `val_nll`); plus
  `ols_reference`.
- `04_mlp_probe/mlp_probe_lr1e-2.json`: `main` keyed `mlp_r{r}_layer_{L}` (raw
  features), `lr_check` keyed `L6_r{r}_lr{lr:g}` (L6 only, all fail), `centered`
  keyed `plain_centered_layer_{L}` and `mlp_r{r}_centered_layer_{L}` (features
  minus the train cross-sample mean). Each entry: `{r, layer, lr, centered,
  n_params, best_val_acc, best_val_nll, best_epoch, final_val_acc,
  final_val_nll}`. Params = 919r (Linear(768,r) + ReLU + Linear(r,150) with the
  second layer bias-free); plain = 115,350.
- `04_mlp_probe/dead_relu_diagnosis.json`: `feature_dim_stats[str(L)]` per-layer
  (pct dims with mu<0, mu+delta<0, mu-delta>0, |mu|>delta, mu histogram),
  `initial_dead[str(L)]` (dead ReLU fraction before training), `trajectory[str(L)]`
  per-epoch `{epoch, train_loss, dead_frac, val_acc}` for L6 and L12.
- `05_act_ablation/act_ablation.json`: `main` keyed `{act}_r128_layer_{L}` and
  `capacity` keyed `{act}_r{r}_L6`; each entry `{act, r, layer, n_params,
  best_val_acc, best_val_nll, best_epoch, final_val_acc, final_train_loss,
  at_uniform (|loss-ln150|<1e-3), neg_frac (h<=0 fraction), n_epochs}`.
  Structure z=W2*act(W1 x + b1)+b2, both biases, 919r+150 params.
- `06_token_variance/token_variance_check.json`: `layers[str(L)]` = list of
  per-position `{pos, n_eff, inter_sample_std, mean_norm}` (positions with
  n_eff >= 300 on a 2000-sample subset; CLS = pos 0).
- `cache/*.safetensors`: tensors `hidden` (N, 12, 768) float16, `labels` (N,)
  int64, `sample_ids` (N,) int64; `cache_manifest.json` with shapes/dtypes/sha256.

## Layer indexing

`hidden[:, l-1, :]` is the CLS of Transformer layer `l` (1..12); layer 12 is the
final layer L. HF `hidden_states[0]` is the embedding output (not probed).

## Reproduction

All probes train on cached CLS features (no backbone forward during probing).
Re-run any phase via `python scripts/diag_run.py {stats,lr_grid,ln_ablation,
optimizer,no_prompt,ft_backbone}` (see `configs/diag_config.yaml`). The 03g ridge
alpha grid is `python scripts/ridge_alpha_grid.py --cache-dir <cache> --label
<label> --out <json>` (one invocation per cache). The 03h Adam ablation is
`python scripts/adam_ablation.py` (9 conditions, layer 6, seed 17, CE to
convergence). Results are deterministic given seed 17 (`deterministic: true`).
