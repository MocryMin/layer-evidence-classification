# Fragmented Experiments — Reports

Single-point exploratory experiments (data collection / direction
exploration). No strict plan, no hypothesis, no accept-protocol.

- One report per experiment point, named `<name>_<YYMMDD>_<NN>.md`
  (daily index starts from 01), e.g. `Qwen3Emb0p6bExp1Ver_260812_01.md`.
- Each report discloses the test configuration and the results.
- Group plans: `user_exp_plans/fragmented_exp-*.md` (e.g. `fragmented_exp_gr1.md`).
- Artifacts: `artifacts/fragmented-experiments/<name>_<YYMMDD>_<NN>/`
  (gitignored).
- Protocol: AGENT_PROTOCOL.md §9.
