# Research proposal workspace

The first proposal will be a 2--4 page LaTeX document for prospective PhD
supervisors. This directory is intentionally a workspace rather than a claim
that a proposal already exists.

Recommended files once drafting begins:

```text
proposal/
  main.tex
  references.bib
  figures/
  rp.pdf
```

Recommended content budget:

1. problem and motivation;
2. precise research gap and relation to prior work;
3. preliminary evidence, using claim IDs C1--C4 from
   `docs/EVIDENCE_INDEX.md`;
4. proposed research questions/methods for the PhD;
5. feasibility, risks, and expected contribution.

The RP should not reproduce experiment logs. It should link once to the
repository and use only the evidence strength allowed by the claim index. Keep
draft-only personal statements, supervisor-specific tailoring, and contact
details outside the public repository.
